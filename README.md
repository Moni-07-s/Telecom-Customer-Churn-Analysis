# Telecom Customer Churn Analysis

A data analytics dashboard for telecom customer churn prediction, customer behavior analysis, churn patterns, and interactive data visualization.

## Project Features

- Customer churn analysis and visualization
- Customer retention insights
- Churn rate and customer segmentation
- Interactive dashboard with charts and KPIs
- Data preprocessing and exploratory data analysis
- Insights to support customer retention strategies

## Installation

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

## Run the Dashboard

Start the Streamlit application:

```bash
streamlit run app.py
```

## Technologies Used

- Python
- Pandas and NumPy
- Streamlit
- Matplotlib / Seaborn / Plotly
- Machine Learning (if applicable)

## Project Objective

To analyze telecom customer behavior, identify factors contributing to customer churn, and generate actionable insights that help improve customer retention and business decision-making.
